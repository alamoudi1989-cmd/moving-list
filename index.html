Click ⚙️ Project Settings in the sidebar

Scroll to "Your apps" → Add app → Web
4
اسم التطبيق اكتب أي اسم ← اضغط Register app
Enter any app name → Register app
5
انسخ قيمة apiKey من الكود اللي يظهر
Copy the apiKey value from the shown code
